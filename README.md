# Flutter Calculator – Version 1 (Basic)

**Status:** ✅ Version 1 – Fully functional basic calculator

---

## Overview

This is the **first version** of a Flutter calculator project.  
It demonstrates a **basic calculator functionality**:

- Two number inputs  
- Operator selection (+, -, *, /)  
- Calculate button  
- Result display  
- Simple validation (e.g., divide by zero, invalid input)

This version is designed as a starting point for future improvements, such as interactive buttons, scientific functions, & full expression parsing.

---

## Features

- ✅ Two input fields for numbers  
- ✅ Operator selection via dropdown  
- ✅ Calculate button  
- ✅ Result display  
- ✅ Input validation  

---

## Getting Started

### Prerequisites

- Flutter SDK  
- Android Studio or VS Code  
- Git  

---

### Installation

1. Clone the repository:

```bash
git clone https://github.com/m-zahir-akbari/flutter_calculator.git
```

2. Switch to Version 1 branch:

```bash
cd flutter_calculator
git checkout v1-basic
```

3. Install dependencies:

```bash
flutter pub get
```

4. Run the app:

```bash
flutter run
```

---

## Usage

1. Enter a number in the **first input** field.  
2. Enter a number in the **second input** field.  
3. Select an **operator** from the dropdown.  
4. Press **Calculate** to see the result.
